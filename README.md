# claude-ae-kit

Plugin **ae-kit** cho Claude Code — quy trình Agentic Engineering spec-anchored với 6 quality gate; intake nhiều nguồn (transcript, tài liệu khách gửi, codebase cũ) đối chiếu chéo thành requirement có nguồn.

- `ae-kit/` — mã nguồn plugin (sửa ở đây)
- `ae-kit-marketplace/` — marketplace local để cài: `claude plugin marketplace add ./ae-kit-marketplace && claude plugin install ae-kit@ae-kit-marketplace`

Tài liệu: xem `ae-kit/README.md`.
